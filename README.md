# Web Scraper – books.toscrape.com

A Python web scraper that collects catalogue and detail data from
https://books.toscrape.com and stores it in SQLite.

## Features
- Deterministic HTML storage
- Resume-safe scraping
- Structured parsing
- SQLite persistence
- Logging and retries

## Architecture
(scraping → parsing → models → repository → database)
